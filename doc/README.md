# Figwright Plus — Documentation

> **Figwright Plus** is an enhanced build of Figwright focused on **LAN collaboration** and **observability**: a web console to manage the whole stack, remote MCP access for peers, per-peer token scoping, structured audit logs, and bilingual UI.

This hub links to the practical guides. Every guide is **bilingual (English / 中文)** — use the link at the top of each page to jump to the other language.

- [Getting Started](./getting-started.md) — install, build, and launch the server + console
- [Peers](./peers.md) — invite collaborators and connect remote agents
- [Skills](./skills.md) — use the `figma-codegen` / `figma-build` agent skills
- [Console](./console.md) — the web dashboard reference
