1核心：结构采样（一切的源）

codegen 唯一真相源。把节点序列化为「结构 + 样式 + Token 名字 + 组件属性」。

工具作用
get_design_context主干工具。支持 detail: full/minimal、dedupeComponents（重复组件折叠）、超大设计自动回 sectionPlan（分段列表）分批采样。

2辅助读取：定位 / 筛选要采样的节点

在采样前找到「采哪里」，以及读设计元信息、标注、字体等。

工具作用
get_selection取当前 Figma 选中的节点。
get_node / get_nodes_info按 id 取单节点 / 批量取节点信息。
get_document / get_pages整棵树 / 页面列表（找顶层 section 用）。
search_nodes按条件搜索节点。
scan_text_nodes扫描所有文字节点。
scan_nodes_by_types按类型遍历（批量导出图片前用它枚举含图节点）。
get_metadata / get_viewport文档元信息 / 当前视口（响应式断点参考）。
get_fonts / get_annotations字体清单 / Dev Mode 标注（设计师给你的注释，最高优先级）。

3复用判定：避免从头造组件 / Token

把 Figma 的组件与变量对接到项目已有的代码组件与设计 Token，命中即复用。

工具作用
component_mapFigma 组件 → 项目已有代码组件，给 high/medium/low/unmapped 状态 + 候选路径。命中即 import 复用，别重写。
token_mapFigma 变量 / 颜色样式 → 项目 Token，给状态 + ref。命中即引 ref，别写死 hex。
get_component_api取组件完整属性 API（所有 VARIANT / BOOLEAN / TEXT 选项），写组件自身定义时用。
get_local_components本地组件库清单（上面两张 map 的底层数据）。
get_styles共享样式清单（颜色/文字/效果样式）。
get_variable_defs变量定义（Design Token 源）。

4资源导出：grounding 带不动的像素 / 矢量

几何 + 文字采样没有像素，logo / 照片 / 图标必须显式导出，否则渲染成灰块。

工具作用
save_image_fills掏 原始图片字节（照片 / 产品图），按 hash 去重，带 scaleMode + 原尺寸，方便 CSS 还原。
icon_map图标优先 复用 项目已有 .svg（lucide / heroicons / iconify 也可引），实在没有才现导。
get_screenshot拍照：PNG（合成，带裁剪遮罩调色，scale:2 才不糊）/ SVG（矢量兜底）。
save_screenshots批量把截图落盘（server 侧写文件）。
export_pdf / export_video导出 PDF / 视频。

5服务端本地分析：增量维护（不碰文档）

纯辅助探针，跑在 server 本地，对 Figma 文档无任何改动。

工具作用
design_diff设计差异对比：首次存基线，之后比「改了啥」（哪些节点 / 属性增删改），做增量同步。
analyze_project项目级栈分析探针（自动推断 React / Vue / Tailwind 等）。
scan_components扫描并内部跑组件检测。
